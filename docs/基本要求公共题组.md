# 基本要求公共题组

## 适用范围

同一项目、同一职业的五级、四级、三级理论知识基本要求共用一套试题。
公共题只有一个题目 ID、一套审核状态；各等级引用公共发布版本。
其他理论知识、操作技能、独立法律法规命题保持各自流程。
各等级仍按自己的权重和试卷结构抽题，不保证实际抽出的题目或题量一致。

## 上线顺序

1. 先在测试环境执行 `database/migrations/0022_common_theory_questions.sql` 并验证，再随应用发布迁移。
2. 正式环境先备份数据库，暂停任务入口并确认没有正在生成、审核、组卷的请求。
3. 使用项目现有 `npm run db:migrate`（需要注入正确的 `DATABASE_URL`）执行迁移，再部署应用。公共题查询不创建数据库 View，业务数据库账号不需要 `CREATE VIEW` 权限。
4. 不要同时运行 `npm run dev` 与 `npm run build`。
5. 迁移只创建公共题组结构并将槽位唯一性从“全局题ID”调整为“任务ID＋题ID”，不自动合并、复制或删除业务题目。
6. MySQL DDL 不支持整体事务回滚。`0022` 已支持续跑：若旧版本在创建 View 时中断，先更新应用代码，再重新执行 `npm run db:migrate`；无需删表、手工写迁移记录或授予 `CREATE VIEW` 权限。

未执行迁移时，不应单独上线新应用版本，因为题库、计划进度与组卷查询需要新增表。

## 管理入口

智能命题顶部“基本要求公共题组”，路径 `/workspace/common-questions`，仅管理员可进入。

1. 先完成五四三级细目表审核确认，确保基本要求共用标识、题目名称及来源一致。
2. 选择职业创建公共题组；三个等级的基本考评点对应关系和依据被冻结保存。
3. 展开“统一配额”，逐考评点配置单选、多选数量。初始建议为4、2，不再生成或选用判断题，管理员可修改，不受等级页面的独立配额覆盖。
4. 可先选择历史题作为初始内容，也可直接生成公共题。
5. 公共草稿人工核查后提交统一审核，通过既有专家分配、审核确定、确认入库流程处理一次。
6. 全部未停用题逐考评点、逐题型满足配额，且当前版本均已入库、已管理员确认后，点击“统一发布”。
7. 各等级新计划引用公共配额，生成时仅生成其余知识题。公共尚未发布不阻塞其余部分生成，但整体计划不能视作已完成。

已有普通理论任务运行时不能创建公共题组。先“停止生成，保留成果”，再选择旧题、建立新版等级计划。
旧计划包含基本要求的，保留全部成果和记录，但不允许继续独立生成这些题目。

页面直接进入时优先打开排队中或生成中的题组，没有运行任务则打开最近更新的题组。指定 `groupId` 链接和手动选择优先保留。
进度区显示已有/已生成数量、目标数、百分比和完成批次，约每5秒更新。复用旧题计入完成量，不代表新的模型生成量。
旧任务按原始题量展示进度，不篡改历史记录；未发布、无判断题成果且没有运行任务的旧题组，在下次生成时自动将判断配额归零并记录审计。
其他旧题组须先停止生成、核对并停用历史判断题，再保存选择题配额。历史试卷和已发布版本不被改写。

## 旧题选用

- 人工勾选并二次确认，不根据相似题干自动合并。
- 只接受同项目、同职业、五四三级理论基本题，校验共用标识及原文来源一致。
- 已关联其他公共题组、正在生成或选用后已变化的题目不能选用。
- 保留原题目 ID、全部题目版本、审核记录、生成来源和历史试卷。
- 选用后题目等级字段为 `NULL`，公共成员关系明确其适用五四三级，不与独立通用法规题混淆。
- 已审定、已入库状态不清零；未审核题不会自动通过。
- 未选用的历史基本题保留可查。公共首版发布后，它们不再作为五四三级新的正式组卷或题库导出候选。

## 修订与发布

- 已审定或已入库公共题从公共管理入口“发起统一修订”，先复制一个待审版本，不覆盖原版本。
- 在现有审核页面编辑新版本、审核、确认、入库，之后再次统一发布公共题组。
- 发布是公共题组级的原子切换，各等级新组卷同时使用新发布版本。未修改题目沿用原版本，不重复审核。
- 维护版本和发布版本分离：修订期间，组卷、正式题库导出继续使用上次已发布的题目版本。
- 历史等级计划记录确认时的配额及公共版本；页面同时展示当前可用发布版和公共缺额。
- 历史试卷保持题目版本及内容快照不变，组卷记录附带公共发布版本 ID。
- 已发布题组的单选、多选配额只允许扩充；取消判断题需先停用对应历史题并保存新配额。旧等级计划快照保留，不自动改写。

## 统一停用

停用需填写原因、二次确认。五四三级同时停止抽取该题，不修改历史试卷。
操作返回关联历史试卷数量，完整试卷 ID 范围写入审计日志。
停用产生的缺额在公共题组补齐；被停用题不占用新生成配额、不进入新发布版。
停用不自动恢复，避免错误题因普通修订或刷新重新可用。

## 依据版本变化

“核对细目表对应关系”读取五四三级最新已确认细目表：

- 共用标识、名称及依据签名均未变化：允许同步新节点对应关系，旧计划快照不修改。
- 来源、内容或公共考评点数量发生变化：拒绝自动沿用题目及审核结论，公共旧版本保持不变，需人工处理。

本次不提供“变更依据后自动承接旧审核结论”。这样不会把旧题未经核对挂到不同职业标准或教材版本。

## 停止与清理

- 等级任务不拥有公共题组，终止等级任务不删除已选用公共题。
- 公共任务停止后保留成果、拦截迟到响应，原任务不可恢复。
- 从公共入口再次明确发起缺额生成时，可建立新任务，原任务计数、记录不清零。
- 公共任务终止仅清理本次生成、未经审核、没有修订或试卷引用的草稿；选用旧题、已审核、已发布题保留。
- 业务清理工具包含公共关联表，仍要求预览、维护确认、备份确认及操作者姓名。

## 数据关系

| 数据表/查询逻辑 | 用途 |
| --- | --- |
| `common_question_groups` | 职业公共题组、冻结依据、统一配额、当前发布版 |
| `common_question_points` | 公共考评点与各等级细目表节点对应关系 |
| `common_question_members` | 一份题目编辑身份、来源与统一停用状态 |
| `common_question_releases` | 不可变的发布记录、依据和配额快照 |
| `common_question_release_items` | 发布时采用的题目 ID 和题目版本 ID |
| `common_question_plan_links` | 等级计划的公共引用及确认时快照 |
| 应用内联公共题源查询 | 各等级可用的已发布、未停用公共题版本，不依赖数据库 View 权限 |

## 验证清单

- [ ] 同职业并发创建或启动只产生一个公共题组/当前公共任务。
- [ ] 五四三级标识、数量或依据不一致时不允许共用。
- [ ] 公共题量逐考评点、逐题型校验，不用总数掩盖缺额。
- [ ] 选用旧题不重复审核、不清除历史，不自动审定草稿。
- [ ] 未入库、未经确认及停用题不能发布或正式抽取。
- [ ] 三等级组卷取同一发布版本，节点映射及各自权重正确。
- [ ] 修订期间旧发布版可用，发布后统一切换，历史试卷不变。
- [ ] 停用后三级同步排除该题，关联历史试卷留痕。
- [ ] 等级终止不误删公共题，公共终止保护已选用和已发布题。
- [ ] 操作技能和独立法规题流程无回归。
